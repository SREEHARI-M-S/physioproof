# PhysioProof

**Can a video prove that a person is physiologically real?**

PhysioProof extracts remote photoplethysmography (rPPG) features and produces
an evidence-oriented authenticity report (not just REAL/FAKE).

## Status

Scaffold — rPPG pipeline and experiments are in progress.

```bash
pip install -e ".[dev]"
physioproof report --demo
```
